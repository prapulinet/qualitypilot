# QP-002 · Supporting text failed minimum color contrast

**Severity:** Medium — reduced readability of navigation and evidence metadata.

**Environment:** Redesigned workspace, desktop and mobile Chromium, axe-core WCAG 2 AA scan.

**Expected:** Supporting text meets the normal text contrast threshold of 4.5:1.

**Actual:** Breadcrumb and footer contrast measured 4.18:1. Step labels measured 4.42:1. Execution timestamps measured 4.03:1. Expanding the scan to generated drafts also found a draft timestamp at 4.34:1; that color was corrected too.

**Fix:** Darken the affected supporting text colors without removing content or disabling accessibility checks.

**Regression coverage:** Automated accessibility scans of all four workspace views on desktop and mobile Chromium. Automated scans are partial accessibility evidence and do not replace manual assistive-technology testing.
