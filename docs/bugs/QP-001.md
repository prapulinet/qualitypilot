# QP-001 · AI generation mode could not be selected

**Severity:** Medium — optional gateway workflow inaccessible from the UI.

**Environment:** Initial v0.1 HTML, Chromium desktop and mobile emulation.

**Steps:** Open the workbench; inspect Generation mode; try to select AI gateway.

**Expected:** Two selectable modes; requesting AI without a configured gateway returns a useful error.

**Actual:** A malformed closing option tag caused the browser to parse the AI label as text. Only baseline was selectable.

**Root cause:** `</option value="ai">` appeared where `</option><option value="ai">` was required.

**Fix:** Correct the option markup.

**Regression evidence:** `AI unavailability is actionable and recoverable` in `e2e/workbench.spec.js` exercises the actual selector, error and recovery workflow on desktop and mobile Chromium.
