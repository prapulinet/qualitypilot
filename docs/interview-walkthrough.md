# Interview walkthrough

Use only statements you can demonstrate. Suggested introduction:

“My background includes three years of manual testing experience and one year of automation experience. I built QualityPilot to practice reliable JavaScript automation and reviewable AI-assisted testing.”

Clarify whether the automation year overlaps your manual experience before stating a total.

## Five-minute demo

1. Explain the business problem and the limits of generated scenarios.
2. Run tests and show a baseline request.
3. Walk through the API validation and one negative test.
4. Explain the injected gateway adapter and why simulated provider tests are not live integration evidence.
5. Show an unfinished roadmap item and explain its acceptance criteria.

## Be ready to explain

- Why use deterministic baseline templates?
- What makes a test assert behavior rather than implementation?
- What happens when the AI gateway fails or produces invalid JSON?
- What remains untested, and which test would you add next?
- How would you isolate test data and debug a flaky UI test?
- How would you evaluate whether generated scenarios improve coverage?
